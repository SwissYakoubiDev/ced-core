## 🏗️ Architecture Technique

*   **Backend :** Node.js (Express), Python (Scripts Data/IA)
*   **Frontend :** React, TypeScript, Vite
*   **Base de Données :** PostgreSQL 16, Redis 7
*   **Hébergement :** Suisse (Infomaniak / Vercel / PlanetScale)
*   **Sécurité :** Chiffrement AES-256, TLS 1.3, 2FA obligatoire

---

## 🤲 Conformité & Éthique

Notre code est développé avec l'intention (**Niyyah**) de servir le bien commun et de respecter les principes de la finance islamique :
*   ✅ **Zéro Riba** (Intérêt)
*   ✅ **Zéro Gharar** (Incertitude excessive)
*   ✅ **Transparence totale** des transactions
*   ✅ **Protection des données** (RGPD / LPD Suisse)
